# Hotel Management System

## Project Overview

The Hotel Management System is a Python-based application developed to simplify and manage basic hotel operations. It provides a role-based system that allows different users to access hotel management features according to their responsibilities.

## Features

- **Admin:** Manage hotel operations and system activities.
- **Manager:** Handle hotel management tasks.
- **Staff:** Access staff-related functions.
- **Customer:** Access customer-related services.
- Role-based login and access.
- Organized hotel management operations.

## Technologies Used

- Python
- Object-Oriented Programming (OOP)

## User Roles

The system includes four main user roles:

1. Admin
2. Manager
3. Staff
4. Customer

Each role has different responsibilities and access permissions.

## Project Objectives

- Develop a simple hotel management application.
- Understand the practical implementation of Python programming.
- Apply object-oriented programming concepts.
- Implement role-based access control.
- Improve basic hotel management operations.

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code or PyCharm.
3. Make sure Python is installed.
4. Open the main Python file.
5. Run the application.
